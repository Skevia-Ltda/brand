# SKEVIA Final Logo — High-Fidelity Vector Reconstruction

Status: **FINAL B reconstructed / production candidate**

This package corrects the rejected v1 implementation and preserves it under `archive/rejected-v1/`.
The approved visual source of truth is **FINAL B — sem ponto** from the SKEVIA Final Logo Refinement board.

## Final geometry
- Symbol construction grid: **173 × 100** (ratio **1.73:1**)
- Symbol: exactly two editable shapes (`LeftShape`, `RightShape`), no point
- Wordmark cap-height basis: **H = 100**
- Wordmark width: **552 units = 5.52H**
- Letter target widths: S=84, K=95, E=76, V=116, I=20, A=105
- The A is open and has **no crossbar**
- The V is split into solid graphite and teal vector shapes, no gradient
- The I contains the only circular point in the brand

## Lockup
- Symbol height in horizontal lockup: **1.33H**
- Symbol width at lockup scale: **230.09 units**
- Gap symbol → wordmark: **58 units = 0.58H**
- Wordmark optical offset: 16.5 units from lockup top

## Color
- Graphite: `#0F1720`
- Teal: `#0F766E`
- Off-white: `#F7F6F3`
- Mineral: `#6B727B`

All production logo assets use solid colors only. No gradients, filters, blur, glow, shadows, raster images, base64 data, external fonts or live text are used.

## Clear space
Initial clear-space unit `x` is the principal visual stem thickness. Recommended minimum clear space: **1.5x** around symbol, wordmark and lockup.

## Minimum digital sizes
- Symbol: recommended **16 px** minimum (tested at 16/24/32/64)
- Wordmark: recommended **120 px** minimum width
- Horizontal lockup: recommended **180 px** minimum width

These values are based on rendered inspection, not arbitrary print conventions.

## Dark and monochrome
- Dark background: off-white + teal
- Mono Dark: `#0F1720` only
- Mono Light: `#F7F6F3` only
- Monochrome geometry remains readable without color separation.
