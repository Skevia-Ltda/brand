# Aplicações

A identidade Skevia utiliza diferentes níveis de presença dependendo do contexto.

## Institucional

Em aplicações de marca, a identidade possui maior presença.

Exemplos:

- website institucional;
- apresentação;
- proposta;
- documento;
- comunicação.

Elementos principais:

- Instrument Sans;
- logo oficial;
- Graphite;
- Teal;
- Off-white;
- grids;
- espaço negativo;
- linguagem de convergência.

## Produto

Em interfaces operacionais, função possui prioridade.

A identidade permanece presente através de:

- cor;
- grid;
- ritmo;
- espaçamento;
- estados;
- hierarquia.

A tipografia principal é Inter.

A interface não deve parecer uma peça de marketing.

## Princípio

A presença da marca deve aumentar quando a comunicação é institucional e diminuir quando a tarefa é operacional.

A Skevia deve continuar reconhecível nos dois contextos.

## Materiais de validação

As aplicações devem utilizar exclusivamente os logotipos atuais da pasta [`logo`](../logo). As pranchas antigas de validação foram retiradas quando a identidade visual foi substituída.
